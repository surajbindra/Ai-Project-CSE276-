# CampusPlan — AI-Based Event Scheduling and Venue Allocation



## Included in this system
- Neumorphic white, orange and black UI
- Supplied LPU logo and campus photograph
- Fixed, continuously rotating 3D logo in the background
- Event requirement form
- Venue filtering using hard constraints (capacity, venue type, equipment and time conflict)
- Penalty-based ranking of valid venues
- Search-state counters and selectable algorithm-ready search function
- Booking confirmation view
- Four  team-member cards
- Policy passage retrieval assistant
